# Launchpad Interview Coach

A local-first, single-page coaching app for software engineering job preparation. No build step or account required.

## Run locally

From this folder, run `python -m http.server 8000` and open http://localhost:8000.

Progress is stored in this browser using localStorage. The resume workshop performs checks in the browser; pasted text is not sent to an API. Its score is a heuristic coaching aid, not a real ATS prediction. Add a specific job description and only claim skills you can demonstrate.

## Curriculum

Six weeks cover role targeting, resume/ATS, coding foundations, debugging, tests, code review and AI-assisted workflows, project and system design, behavioral stories, and mock interviews. Hiring formats vary by company, country, role, seniority and team.
